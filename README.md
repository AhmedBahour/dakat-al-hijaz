# دكّة الحجاز | Dakat Al Hijaz

الموقع التعريفي الرسمي لمقهى دكّة الحجاز، ويضم المنيو الرقمي، معرض صور المنتجات والجلسات، ساعات عمل فرعي جدة والنماص، وطرق التواصل والوصول.

## التشغيل محلياً

الموقع ثابت ولا يحتاج إلى تثبيت حزم. افتح `index.html` مباشرة أو شغّل خادم ملفات محلياً.

## النشر

يُنشر الموقع تلقائياً على GitHub Pages عند الدفع إلى فرع `main`.
